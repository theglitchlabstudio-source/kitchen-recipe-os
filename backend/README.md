# به‌روزرسانی اسکریپت گوگل شیت (نسخهٔ ۲)

بخش‌های جدید اپ (تیم، انبار، دورریز، کانتر) تا وقتی این مرحله انجام نشود **فقط روی همان گوشی/مرورگری که ثبت شده‌اند** ذخیره می‌شوند و در صف ارسال می‌مانند. بعد از نصب، صف خودکار به شیت فرستاده می‌شود و چیزی از دست نمی‌رود.

رسپی‌ها، مواد اولیه و بازخوردها مثل قبل کار می‌کنند و به این مرحله وابسته نیستند.

## مراحل

1. شیت را باز کن ← **Extensions › Apps Script**.
2. کنار `Code.gs` یک فایل تازه بساز (`+` ← Script) به نام `KitchenOS_v2` و محتوای [`KitchenOS_v2.gs`](KitchenOS_v2.gs) را داخلش بچسبان.
3. در `Code.gs` دو خط اضافه کن:
   - داخل `doGet`، درست قبل از برگرداندن JSON (شیئی که `team`، `recipes`، … دارد):
     ```js
     result = kos2_extendGet(result);
     ```
   - اول `doPost`، بلافاصله بعد از `JSON.parse` بدنهٔ درخواست:
     ```js
     var kos2 = kos2_handlePost(payload);
     if (kos2) return kos2;
     ```
   (اسم متغیرها را با کد خودت تطبیق بده.)
4. **Deploy › Manage deployments** ← روی deployment فعلی ✏️ ← Version: **New version** ← Deploy.
   مهم: «New deployment» نزن؛ آدرس عوض می‌شود و اپ دیگر وصل نمی‌شود.
5. اپ را رفرش کن. نشانِ «محلی» کنار دکمه‌ها باید به «در صف» و بعد ناپدید شدن تغییر کند.

## شیت‌هایی که خودکار ساخته می‌شوند

| شیت | محتوا |
|---|---|
| `inventory_items` | کالاهای انبار، واحد، حد سفارش، نام‌های دیگر در رسپی‌ها |
| `stock_moves` | ورود، مصرف (با بخش)، دورریز، شمارش موجودی |
| `waste_log` | تست‌های بازده: قبل/بعد از فرایند، بازده٪، علت |
| `tickets` | فیش‌های کانتر: شماره، اقلام، وضعیت، زمان تحویل |
| `daily_reports` | جمع‌بندی بسته‌شدهٔ هر روز کاری |
| `settings` | بخش‌های آشپزخانه، ساعت شروع روز کاری |

شیت تیم موجود (`chef_name`, `station`) دست نمی‌خورد جز وقتی که از اپ تیم را ویرایش کنی؛ ستون‌های اضافه‌ای که خودت به آن اضافه کرده باشی حفظ می‌شوند.

## پروتکل (برای لایه‌های بعدی)

- `GET` ← همان خروجی قبلی + `kos: {version: 2}` + جدول‌های بالا.
- `POST {action: "kos_batch", ops: [...]}` که هر op یکی از این‌هاست:
  - `{op: "upsert", table, row}` — ردیف با `id` یکتا درج یا جایگزین می‌شود.
  - `{op: "delete", table, id}`
  - `{op: "team", rows: [{chef_name, station}]}` — کل فهرست تیم.
