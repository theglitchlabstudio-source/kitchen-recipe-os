# kitchen-recipe-os

سیستم مدیریت آشپزخانهٔ سوسیسا — یک فایل `index.html` که به گوگل شیت وصل است.

## بخش‌ها

- **رسپی‌ها** — ویرایش رسپی، مواد اولیه، بازخورد؛ با لمس متن مراحل، **کارت کامل تک‌برگ** باز می‌شود که بدون اسکرول خوانده می‌شود (قابل چاپ).
- **کانتر** — ثبت فیش، فیش‌های باز با زمان‌سنج، تحویل/لغو، گزارش روزانه (کل، تحویل، باقی‌مانده، لغو، میانگین زمان، اقلام).
- **انبار** — یافتن مواد اولیه از دل رسپی‌ها (با تشخیص نام‌های تکراری)، ثبت ورود/مصرف/دورریز/شمارش، مصرف هر بخش.
- **دورریز و بازده** — مقدار قبل و بعد از فرایند ← بازده٪ و دورریز، میانگین وزنی هر ماده.
- **تیم** — افزودن، ویرایش و حذف سرآشپزها.
- **خروجی JSON** — دکمهٔ ⬇ بالای صفحه، همهٔ اطلاعات در یک فایل.

## حفظ داده

- `data/backup-2026-10-03.json` — نسخهٔ کامل داده‌های شیت در لحظهٔ این به‌روزرسانی.
- همین نسخه داخل `index.html` هم جاسازی شده؛ اگر شیت در دسترس نباشد اپ خالی نمی‌شود.
- ویرایش‌های ذخیره‌نشدهٔ رسپی و همهٔ ثبت‌های بخش‌های جدید روی دستگاه نگه داشته می‌شوند و با رفرش یا بستن تب از بین نمی‌روند.
